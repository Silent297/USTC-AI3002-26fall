## 4. 实际验证记录

环境：ai26（Python 3.12.14、torch 2.11.0+cpu），CPU，float32；工作目录 `code/q2_clustering`。

```bash
python extras.py run --device cpu --development \
  --input ../../_tmp/T0007/toy_features.npz \
  --config ../../_tmp/T0007/config_dev.json \
  --output outputs_dev_T0007_20261119_01
python extras.py check-output --development \
  --input ../../_tmp/T0007/toy_features.npz \
  --output outputs_dev_T0007_20261119_01
```

- `run` 退出码 0，耗时 0.40 s；8 个候选全部 `succeeded`，KMeans 以 `labels_unchanged` 停止，GMM 以 `nonnegative_mean_likelihood_change` 停止，GMM 似然历史无下降。
- `check-output` 退出码 0，返回 `passed: true`：`clusters.npy` 形状 (120,)、int32、actual_k=2、簇大小 [60, 60]、assigned=120。

逐候选结果：

说明：GMM 的 K=3 候选权重之和为 1、方差为正（最小约 5.6e-2），但硬分区的 actual_k 为 2，说明第三个分量未在任何样本上取得最大责任度。这是 toy 两团数据上的现象，不构成对正式数据的结论。

选择结果：`selection.json` 为 `selected`，方法 KMeans、K=2、代表运行 `kmeans_k2_seed17`、restart 0。K=2 的 KMeans 与 GMM 三项指标在 1e-6 内并列，按规则优先较小 K、再优先 KMeans；组内两个种子目标值相同，按 1e-7 相对容差取较小 seed 17。`export_manifest.json` 记录模型与标签哈希；`model.npz` 中 centers、preprocessing 均为有限值；`candidate_clusters.npz` 保存 8 个候选的 (120,) 分区。

未验证：正式 56000×512 数据的耗时、收敛和内存；GPU 路径；隐藏标签 ACC；check-output 只检查格式、哈希与来源，不评价聚类质量。
