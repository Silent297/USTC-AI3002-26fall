# Q1 三项拓展实验设计

本设计检验双峰函数的层次构造、训练稳健性及梯度传播解释。课程要求的八组结果仍单独保留；拓展实验不能代替基线，也不能用有限次训练证明所有浅层网络无法表达目标。实验 1 为无训练的 CPU 前向验证；实验 2、3 尚未运行，多配置训练须使用学校 Slurm。

## 实验 1：构造性验证与第二层激活消融

**问题。** 用 ReLU 与线性运算写出的双峰构造能否由实际 MLP 实现？在同一组权重下，第二次非线性截断承担什么作用？

目标为 f(x)=Σ_c max(0,1-(|x1-c|+|x2|)/0.6)，c∈{-0.65,0.65}。网络沿用课程 D 的 [8,4]、65 参数结构。第一层为每个峰分别计算四个正部项；第二层的前两个单元形成两个截断峰，其余两单元和输出对应权重置零。明确中间量 s_c 是四个正部项的**未缩放和**，第二层计算 ReLU(1-s_c/0.6)，避免重复除以 0.6。

| 对照 | 权重与数据 | 第二隐藏层激活 | 训练 |
|---|---|---|---|
| 完整构造 | 相同手工权重、相同点 | ReLU | 无 |
| 激活消融 | 完全不变 | 恒等映射 | 无 |

消融仅对第二层进行，第一层 ReLU 保留。调用已有 MLP 检查完整网络，旁路第二层激活得到消融输出；另外验证消融后的两个相邻线性映射可折叠，以确认干预只移除了这一层非线性。

**固定评价方案。** CPU 单线程，float64 为构造核对、float32 为实际计算精度对照；保留原训练点 1024、原网格 65×65，增加 201×201 密网格、10000 个固定均匀随机点（seed=20261123）与峰顶/谷底/支撑边界等人工探针。增加的评价点不参与训练或调参。目标用独立 NumPy 距离/截断运算生成，并与课程原始标签额外对照。

**指标与图。** 每组点记录 MSE、最大绝对误差、目标峰区（f≥0.5）误差、背景（f=0）误差；为空的子集记录 null。保存二维预测/误差图、x2=0 截面和探针表。float64 完整构造的 max_abs_error≤0.000000000001、float32≤0.000002 为预先设定的数值核对阈值，不以“消融必须失败”作为程序成功条件。额外记录原 float32 标签与 float64 参考之间的差异。

**解释边界。** 完整构造正确支持“存在这样的网络参数”；消融误差揭示这一组构造对第二层截断的依赖。消融后不重新训练，不能据此断言任意浅层网络在有限区域上都不能逼近目标，也不能说明优化器一定能找到手工参数。

## 实验 2：等参数量、多初始化与配对训练预算

**问题。** 两隐藏层在本题中的优势是否跨初始化存在？浅层训练平台是否可能包含优化因素？

| 因素 | 固定设计 |
|---|---|
| 网络 | 浅层 [16] 与两隐藏层 [8,4]，均为 65 参数 |
| 种子 | [17,42,123,2026,20261123]，预先固定，不筛选 |
| 训练 | 每条轨迹训练 9000 步，保存 0、3000、9000 步快照 |
| 固定条件 | 课程 expression 数据、ReLU、Adam、lr=0.01、全批量平均 MSE |
| 初始化 | 统一使用同一种 Linear 初始化规则，保存所有初值；不载入手工构造参数 |
| 规模 | 2 结构×5 种子=10 条轨迹；两预算点共20条终点记录 |

不同结构下同种子不等于同权重；其配对只能控制随机种子的记录方式。同一结构、种子的 3000/9000 步则来自同一轨迹，避免两次随机训练混淆预算作用。正式设备、dtype 和初始化版本需在 sbatch/运行记录中固定。

**交付。** 每种结构的网格 MSE 散点及中位数/范围、3000→9000 的配对变化、最大误差/峰区/背景误差、参数量与耗时；不删除坏种子或只展示最好一次。预先固定评价点，不能用评价网格选种子后再宣称普遍优势。

**可能结论。** 深层多数种子更好支持稳健性；浅层部分种子改善提示原平台可能包含优化因素；深层也失败说明可表示性与可学到性不同。十条轨迹均不足以证明全体初始化、全体浅层宽度或全体优化器的性质。

## 实验 3：深度与激活对梯度传播的影响

**问题。** 前层梯度变弱是否随深度增加，并在改变激活后发生系统差异？

| 因素 | 固定设计 |
|---|---|
| 深度 | 2、4、8 隐藏层，每层32单元 |
| 激活 | Sigmoid、ReLU |
| 种子 | [17,42,123] |
| 配对 | 同深度同种子的两种激活加载完全相同的 Linear 初值 |
| 固定条件 | 课程 gradient 数据、SGD、lr=0.05、1000步、全批量平均MSE |
| 规模 | 3深度×2激活×3种子=18条轨迹 |

**测量。** 按课程固定128样本诊断口径记录初始与训练后逐层梯度 RMS、相对输出梯度 ρ、局部激活导数均值；补记各层权重范数、激活统计、训练/网格 MSE。输出端梯度为0时相对比值记未定义，不把它改成0或静默删除。

**交付。** 各种子的初始/最终梯度剖面、首层相对梯度随深度的散点及拟合误差对比。初始测量用于减少训练轨迹变化的混杂；跨深度参数量与权重乘积同时改变，不能声称激活导数是唯一原因。ReLU 不保证所有输入路径都能有效传梯度。

**启动条件。** 与实验2相同，另行认领、独立配置/输出与 Slurm 作业；不在本机运行此多配置训练。
