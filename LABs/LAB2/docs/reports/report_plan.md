> 版本：2026-11-19，TD001。只定结构、口径和分工；**不预写实验结果与分析结论**，等正式实验完成后再填。

## 1. 目标与约束

- 最终交一份覆盖两题的 PDF，两题各 50 分；报告格式自定。
- 报告围绕实验结果和分析题，避免重复题面、粘贴大段代码或完整日志；过长会影响评分。
- 必须写清实际环境、运行命令和关键配置；完整日志与原始输出只在本地保留至验收。
- Q2 只能有一个正式输出；选择依据必须来自无监督指标、跨种子表现和簇结构。
- 不使用真实标签；多数票 ACC 只在教师侧计算，报告不得声称或推算。
- 数值用十进制书写（如 `0.00686`），不用科学计数法；同一指标保持一致有效位。
- 结果段只写直接观察，原因与边界放在分析段；分析题引用前文图表，不重复读数。

## 3. 各章写法

### 3.1 第一题

1. **设置速览**：一张八行表列出隐藏层、参数量、更新次数、激活、学习率、优化器与 batch；两三句话说明 MLP 与训练循环的实现要点，不贴代码。
2. **实验 A 结果**：网格 MSE/训练 MSE 表，训练曲线，`x2 = 0` 截面对比；观察只写差异，不下结论。
3. **实验 A 分析**（a/b/c）：按分值分配篇幅；(a) 结合截面与误差分布说明“平均 MSE 小”是否足够；(b) 用 ReLU 与线性运算逐层构造目标，说明单隐藏层缺什么；(c) 比较多训练、加宽、加深的效果与代价。
4. **实验 B 结果**：两组指标表，训练曲线，训练前后逐层相对梯度图；先定义 `ρ` 与固定样本口径。
5. **实验 B 分析**（a/b/c）：(a) 用梯度证据判断梯度消失，并说明为什么不能只看损失；(b) 比较换激活后的梯度与拟合变化及原因；(c) 区分学习率改变的是梯度还是更新幅度。
6. **小结**：3–4 句，不引入新结论。

### 3.2 第二题

1. **数据与设置**：数据形状/类型、全部样本、无标签、预处理、K/种子/初始化/迭代/收敛参数、精度与设备、Silhouette 抽样口径、评价空间、选择规则。用表 3 一次写全。
2. **实现与自检**：五个算法函数与三个评价函数各一段；列出分项自检、完整测试、独立对拍和 `check-output` 的实际结果，不展开代码。
3. **实测比较**：表 4 按“方法 × K”汇总跨种子均值/波动、CH、DB、训练目标、最小簇大小、迭代与耗时；图 5 看指标随 K 的变化，图 6 看簇大小结构，图 7 看跨种子分区一致性（ARI，仅作分析）。惯性/对数似然分列并注明不可直接比较。
4. **T1 最终选择**：按“规则 → 证据 → 与其他候选比较 → 指标局限”四段回答；写明最终 `run_key`、代表种子、`clusters.npy` 哈希与 `check-output` 结果。若正式结果是 GMM 胜出，方法段随之改写。
5. **T2 现象分析**：正式结果出来后再选一个现象，优先考虑“指标随 K 的突变/极小簇/跨种子分歧”这类有图表支撑的对象；按“现象 → 排除其他解释 → 算法原理 → 适用范围”写，只分析一个主现象。
6. **局限**：抽样与全量口径、两个种子不是置信区间、单一数据集、无真实标签、主指标偏好。
