## P1：学习率过小造成慢收敛的反例

目的：为实验B(a)补充“损失下降慢不足以诊断梯度消失”的直接对照。Sigmoid饱和可能正是梯度消失的原因，不将其当作独立反例。

| 因素 | 预定设置 |
|---|---|
| 模型 / 数据 | 无隐藏层的带偏置线性模型，3参数；课程gradient的固定1024点及4225评价网格 |
| 对照 | SGD，学习率0.05与0.00001；每次1000步、全批量平均MSE |
| 配对 | 种子17/42/123；同种子的两学习率严格共享初始权重，共6条轨迹 |
| 记录 | 训练/网格MSE、参数梯度范数、实际更新范数、首尾参数及源配置；初始梯度应相同 |
| 参考 | 已知目标为可精确表达的线性函数，可检查解析解/最小二乘残差，区分表达能力与优化预算 |
| 执行 | 先独立脚本/sbatch与toy冒烟，再提交学校Slurm；本次只登记 |

无多层反传链可排除这里的层间梯度消失机制。若小学习率下梯度与对照同量级，但更新小、MSE下降慢，则形成所需反例。不能据此声称原8层Sigmoid的问题就是学习率，也不能预填本次尚未得到的数值。先固定全部设置，不根据结果更换种子。

## P2：Q2更多种子与邻近K的稳健性

目的：检验K=10相对邻近候选的优势和两个方法的初始化稳定性，替换“只比较两个种子就不依赖初始化”的过强表述。

| 因素 | 预定设置 |
|---|---|
| 方法 / K | KMeans、对角GMM；K=[8,10,12] |
| 种子 | [17,42,123,2026,20261123,7,11,29,101,314]，共10个，事前固定 |
| 重启 / 规模 | n_init=3，共60个候选、180次重启；同种子列表供两方法使用 |
| 数据 / 预处理 | 全56000×512数据，每次全部拟合，行序不变，不标准化、不使用真实标签 |
| 算法参数 | 沿用原正式配置：KMeans200步/tol0.0001；GMM100步/tol0.0001，reg_covar=0.0001，float32，threads=4 |
| 评价 | 同一3000行Silhouette子集，seed20261011；CH/DB全量原始空间；不把抽样变化混入拟合种子变化 |
| 执行 | T0016已准备新配置、新输出和独立Slurm脚本，保留原八K结果；正式作业尚未提交，见[P2执行说明](p2_robustness.md) |

交付全部种子的指标分布、失败/不收敛情况、实际簇数与大小、每个种子下邻域K比较；各方法/K的两两ARI报告最小值/中位数/范围。10个种子得到45对ARI，但这些比较共享运行、并非45次独立试验；n_init=3内部重启也不能冒充额外外部种子。

本方案只检验K=8/10/12邻域，不声称10个种子覆盖原八个K。若将来要直接重做原八K整体选择，应单独明确扩展为两方法×八K×十种子=160候选、480重启。正式最终标签是否更换另行审查，不手工复制某个最好种子冒充框架导出。

## 如何进一步比较GMM和KMeans

现有K=10结果的Silhouette均为0.9612787365913391，跨方法ARI约0.9997，CH/DB仅略偏向KMeans。当前应视为质量近似并列，不能承诺新实验一定分出胜负。

本次先做了一项现有产物的只读核对：对Job177703的kmeans_k10_seed17与gmm_k10_seed17标签做最大重叠簇号匹配后，56000行中只有7行分组不同（0.0125%），且这7行均不在保存的3000行诊断子集中。在该子集上两者分区相同，所以相同Silhouette并不说明全量标签完全一致。对齐差异不是分类错误数，没有真实标签时不能据此认定哪一方更准确。已保存的中心以及GMM权重/均值/方差可用于后续检查。

除上述标签计数外，以下方案仍是建议，尚未系统执行；未重新拟合或改动正式输出。

| 思路 | 可以做什么 | 决策用途与限制 |
|---|---|---|
| 分析争议样本（优先） | 读取现有两个候选的clusters.npy，用最大重叠匹配对齐簇号；统计真正改变分区的样本，检查其邻域、中心距离、GMM责任度及对应方差。 | 先定位差别是否只在少数边界点；标签编号不同本身不算分区差异。近邻几何也带有假设，不能当作隐藏类别真值；GMM责任度与KMeans距离间隔不直接比较数值大小。 |
| 评价抽样敏感性 | 冻结现有候选分区，使用多个预先固定的Silhouette抽样种子；每轮两方法共享子集，不挑选最有利的一轮。 | 不必重新拟合，可研究当前相同分数是否受抽样覆盖影响；评价回放遵守原设备/精度，CUDA运行需Slurm，不能把随机子集当独立数据集或精确真值。 |
| 稳定性（先做P2） | 用更多种子检验各方法是否重复得到相似分区，比较失败和极小簇，而非只看平均分数。 | 衡量优化流程的稳健性；稳定并不等于聚类正确。若两者都稳定，不能强行推出某个更优。 |
| 小扰动敏感性（可选） | 在预先规定的低幅度、按各维尺度定义的无标签特征扰动下，用相同扰动比较冻结模型的标签翻转/ARI；若研究拟合稳定性，再独立全量重拟合。 | 必须区分预测敏感性与重新拟合稳定性；噪声模型有假设，过强扰动会改变问题。新增GPU或全量运行走Slurm。 |
| 代价与模型复杂度 | 固定K=10及同等重启预算，排除预热后同步计时，比较耗时/显存、收敛；GMM额外学习方差和混合权重，KMeans只需中心。 | 若质量和稳定性接近，较小代价/较简单模型可作为合理选择依据；现有极短单次耗时不足以支持强结论。 |

比较前应先明确“更好”指硬分区质量、稳健性还是运行代价。当前课程只交硬标签，GMM的密度/软分配能力只有在对应需求下才是额外价值。不能直接比较KMeans惯性与GMM对数似然，也不把仅对GMM计算的AIC/BIC作为两方法质量比较的共同标尺。

如果补充证据仍不能显示实质质量优势，保留两者近似并列，并依据预设规则和实际代价选择一个可复现的输出，是可接受的结论；不把该决策包装成已证明KMeans的真实类别准确率更高。
