# A6 逐图解释说明（L1 稠密性定量：非零系数 vs λ1）

> 实验：`experiments/A6/` —— 拓展实验 A 系列（附加探究，非课程必交内容）。问题：**Qwen3-4B-Base 的 2560 维隐藏表征在 L1 正则下到底有多稠密？要把一半/九成的维度压到零需要多大的 λ1？在这个稀疏化过程中 valid 指标怎么变？**
> 来源：《可做实验清单》A6（指南1 §4.3.2 与创新点 1/7：指南称"λ1=0.01 时仍有 1860 个非零系数，表征是稠密的，L1 全程有害"）。我们复现其密度曲线，但不预设"有害"结论，按任务分别报告。
> 协议：特征按 train 统计量 z-score；λ2 固定在 A1 锚点（world **1.0**、truth **1e-3**）；λ1 网格从大到小、**warm start** 连续求解；目标函数与 `model.py` 完全一致（linear: $\frac1N\|Xw+b-y\|^2+\lambda_1\|w\|_1+\lambda_2\|w\|^2$；logistic: $\frac1N\sum[\log(1+e^z)-yz]+\lambda_1\|w\|_1+\lambda_2\|w\|^2$）。**valid 只报告、不参与任何选择**。
> 求解器：FISTA + 软阈值（近端 L1），tol=1e-7、max_iter=3000；不使用 `model.py` 的 `sign()` 次梯度（它在 0 点振荡、永远得不到精确零，见 §0.4）。对 world 的二维输出，`nonzero` 定义为"**至少一个输出非零的隐藏维度数**"，分母 2560；条目数另行给出。
> 数值自检：λ1→0 时 world valid MSE **167.1705**（A1 锚 167.1707）、truth L20 valid acc **0.8633**（A1 锚 0.8667，差异来自 λ1=1e-5 而非严格 0 及 FISTA 收敛精度）；λ1=λ1_max 时 world 的 w 精确为 0、truth 的 p 四舍五入后为 0.5（logloss=log 2）。
> 产物与复现：`PYTHONIOENCODING=utf-8 python experiments/A6/a6_l1_density.py`（本地 CPU，**366.4 s**，全部记录 `converged=True`）；`--recompute-metrics` 从已保存权重重算指标，`--replot` 只重画图。`a6_results.json`、`a6_l1_density.csv`、`a6_weights.npz`、`a6_run.log`；图在 `figures/`。
> 维护约定：每完成一批绘图，在实验目录下新建 `aX_figure_notes.md`，格式同本文与 `experiments/A10/a10_figure_notes.md`。

| 图 | 一句话 | 回答的内容 |
|---|---|---|
| `a6_density_curves` | 非零维数 / 百分比 vs $\lambda_1/\lambda_1^{max}$（log x，三条任务曲线） | "多稀疏、需要多大 λ1" |

**一句话主线**：表征确实稠密——要把一半维度压到零，world 需要 $\lambda_1\approx1.18$（**1.29%** 的 λ1_max），truth L20/L23 需要 $\lambda_1\approx7.7\times10^{-4}$ / $7.3\times10^{-4}$（**0.34%/0.39%** 的 λ1_max）；要压到 10% 则分别需要 **10.7% / 3.9% / 5.0%** 的 λ1_max。**但"L1 全程有害"在我们这套协议下不成立**：world 在 λ1=0.1 时 valid MSE 从 **167.17 降到 165.90**（−0.76%）；truth L20 在 λ1=0.01 时只保留 **217/2560** 维，valid 准确率却从 **86.67% 升到 89.00%**（+2.33pp），valid logloss 从 **0.4835 降到 0.2948**；truth L23 的 logloss 也从 0.4865 降到 0.3150（λ1=0.003）。**L1 的效果是"先小幅改善、后急剧崩溃"**，不是单调有害；指南的"1860 非零"数字与我们的任务/λ2 协议不可直接比较。

|---|---|---|---|---|

| truth L20 | **0.225972** | λ1≈**7.71e-4**（f=0.00341） | λ1≈**8.87e-3**（f=0.0393） | **217/2560**（8.48%） |
| truth L23 | **0.187965** | λ1≈**7.31e-4**（f=0.00389） | λ1≈**9.45e-3**（f=0.0503） | **241/2560**（9.41%） |

> f = λ1/λ1_max；50%/10% 由相邻网格点在对数 λ1 上线性插值。world 的 `nonzero` 是"至少一个输出非零的维度数"；条目数在 λ1=0.01 时是 5119/5120。

- λ1→0 的极限：world 在 λ1≤0.001 时 2560/2560 维全非零；truth L20/L23 在 λ1=1e-5 时仍有 **2522/2560（98.5%）** 维非零（`nonzero_1e-6` 分别为 2522 / 2521；更小 λ1 的残差可忽略）。
- 在 λ1=0.03（L20/L23 都接近"删掉 97%"）时，非零维数分别只剩 **72 / 87**。

### 0.4 求解器检查：`sign()` 次梯度 vs 近端 L1（world L11，λ1=0.01，λ2=1.0）

| 方法 | 非零条目 | >1e-6 的条目 | train MSE | 备注 |
|---|---|---|---|---|
| `model.py` 风格 `sign()` 次梯度（lr=1.788e-3，800 epoch） | **5120/5120** | 5109 | 92.929 | 无精确零；未完全收敛 |
| FISTA + 软阈值（本文） | 5119/5120（行数 2559/2560） | 5119 | **92.086** | 有精确零、目标更低 |

> 结论：`sign()` 次梯度在 0 点附近来回跳跃，非零集合始终是全部维度；要研究"L1 能删掉多少维"，必须用近端方法（FISTA/ISTA）或坐标下降。`model.py` 的 `sign()` 只适合观察 L1 的收缩效果，不适合做密度统计。

## 1. `a6_density_curves.*` — 非零系数 vs 稀疏压力

**画的是什么**：左 = 非零隐藏维数（world 是"任一输出非零"的行数；truth 是 1D 权重），右 = 非零百分比；x 轴是 $\lambda_1/\lambda_1^{max}$（log），三条曲线：world L11（蓝）、truth L20（橙）、truth L23（紫）。水平虚线 = 2560（全维），点线 = 1280（50%）。

**关键读数**（§0.1）：
- λ1→0：三条曲线都在 2560 附近；truth 在 f≈1e-4 之前基本不掉维，world 直到 f≈1e-3 才开始掉。
- **50%**：world λ1≈**1.179**（f=0.0129）、L20 λ1≈**7.71e-4**（f=0.00341）、L23 λ1≈**7.31e-4**（f=0.00389）。
- **10%**：world λ1≈**9.787**（f=0.1071）、L20 λ1≈**8.87e-3**（f=0.0393）、L23 λ1≈**9.45e-3**（f=0.0503）。
- λ1=λ1_max：world 0 维；truth 1 维（数值残差，指标已按 p=0.5 处理）。
- truth L20 与 L23 的曲线几乎重合（同一模型不同层），说明"密度 vs λ1"的几何形状在 truth 任务内很稳定；world 曲线整体右移，说明 world 的权重尺度更大、需要更强的绝对 λ1 才能稀疏化（但按 λ1_max 归一后差距缩小）。

**证明了什么**：
1. **表征是稠密的**：要让一半维度精确为零，只要 0.34%–1.3% 的 λ1_max；要让 90% 维度为零，需要 3.9%–10.7% 的 λ1_max。**"稠密"不是"删不动"，而是"要删掉一半需要相对很小的 λ1"**——这正是指南"1860 非零"想表达的意思，但具体数字依赖 λ2/任务。
2. **truth 比 world 更容易稀疏化**：同样保留 50% 维度，truth 只需 world 约 1/4 的 f；这与 truth 的 logistic 损失曲率更大、权重更集中一致。
3. **λ1=0.01 不是"稠密"的统一证据**：world 在该 λ1 下仍有 2559/2560 维（几乎全稠密），truth L20/L23 只剩 217/241 维（已相当稀疏）。**同一个 λ1 在不同任务上含义完全不同**，报告里必须带 λ1_max 或 f。

**报告怎么用**：A6 的主图。正文引用 50%/10% 两个锚点，说明"表征稠密但可稀疏化"；如果只放一张图，用本图（左右 panel 一起）。
图注候选（中文）：*"A6：L1 稀疏压力 vs 非零隐藏维数（world L11、truth L20/L23；x 轴按各自 λ1_max 归一）。要让一半维度精确为零，三个任务分别只需 λ1/λ1_max≈0.013、0.0034、0.0039；要压到 10% 则需 0.107、0.039、0.050。同一 λ1=0.01 在 world 上仍近乎全稠密（2559/2560），在 truth 上只剩 8.5%–9.4%。"*
图注候选（English）：*"A6: L1 sparsity pressure versus the number of nonzero hidden dimensions (world L11, truth L20/L23; x-axis normalised by each task's λ1_max). Halving the dimensions requires only λ1/λ1_max≈0.013, 0.0034 and 0.0039; reaching 10% requires 0.107, 0.039 and 0.050. The same λ1=0.01 leaves world almost fully dense (2559/2560) but keeps only 8.5%–9.4% of the truth dimensions."*

## 2. `a6_metric_vs_l1.*` — 稀疏化的代价/收益

**画的是什么**：左 = world valid MSE（对数坐标，虚线 = A1 的 L2 锚 167.17；插图放大 $\lambda_1/\lambda_1^{max}\le0.03$、y∈[160,190]）；右 = truth valid accuracy（%，点线 = L2 锚 86.67%/85.00%）。x 轴均为 λ1/λ1_max（log），竖虚线在 f=1（λ1_max）。

**关键读数**：
- **world**：valid MSE 从 λ1=0 的 167.17 缓慢降到 λ1=0.1 的 **165.90**（−0.76%），然后 166.82（0.3）→183.49（1）→242.64（3）→496.87（10）→1356.6（30）→3311.3（λ1_max）。插图把这个浅极小放大了：曲线在 f≈1e-3 处比锚线低约 1.3 个 MSE。
- **truth L20**：86.67%（锚）→87.00%（0.001）→86.67%（0.003）→**89.00%（0.01，217 维）**→85.33%（0.05）→83.00%（0.1）→76.67%（0.15）→50%（λ1_max）。
- **truth L23**：85.00%（锚）→**86.33%（0.001，1111 维）**→85.67%（0.003）→84.00%（0.01）→80.33%（0.05）→78.67%（0.1）→77.67%（0.15）→50%（λ1_max）。

**证明了什么**：
1. **L1 不是单调有害**：world 有 −0.76% 的浅收益；truth L20 的 valid acc 提升 +2.33pp（7/300 条），L23 提升 +1.33pp（4/300 条）。指南"L1 全程有害"的结论在我们的 z-score + 固定 λ2 协议下**不能原样复现**。
2. **收益与稀疏度不是同一件事**：L20 的最佳 acc 在 217 维，最佳 logloss 在 609 维（λ1=0.003，0.2747）；L23 的最佳 acc 在 1111 维，最佳 logloss 在 562 维。**"保留多少维"取决于用 accuracy 还是 logloss 选**，这也说明只报 accuracy 会漏掉校准信息。
3. **崩溃是陡峭的**：truth 从 λ1=0.03 到 0.15，acc 从 86.67% 掉到 76.67%；world 从 λ1=1 到 30，MSE 从 183 涨到 1357。**可用区间很窄**，λ1 需要 CV 选，不能拍脑袋。
4. valid 峰值是描述性的：+7/300 条的正确数在 n=300 上并不算大，报告里应避免写成"显著提升"（未做配对检验；若要下结论需 McNemar/bootstrap）。

**报告怎么用**：A6 的"代价/收益"图。正文建议同时给出 world 和 truth 两个 panel，强调"温和 L1 可能小幅有益、强 L1 迅速有害"；插图用于说明 world 的 −0.76% 是真的（不是锚线画错）。
图注候选（中文）：*"A6：valid 指标随 L1 强度的变化（valid 仅用于报告）。world 的 valid MSE 在 λ1=0.1 处出现 165.90 的浅极小（锚 167.17，−0.76%），λ1≥1 后迅速恶化；truth L20 在 λ1=0.01（217/2560 维）达到 89.00% 的 valid 准确率（锚 86.67%），L23 在 λ1=0.001（1111 维）达到 86.33%。λ1→λ1_max 时退化为 50% 的常数预测。"*
图注候选（English）：*"A6: valid metrics versus L1 strength (valid used for reporting only). World valid MSE has a shallow minimum of 165.90 at λ1=0.1 (anchor 167.17, −0.76%) and collapses for λ1≥1. Truth L20 reaches 89.00% valid accuracy at λ1=0.01 (217/2560 dimensions; anchor 86.67%), and L23 reaches 86.33% at λ1=0.001 (1111 dimensions). As λ1→λ1_max both degenerate to the 50% constant predictor."*

## 3. `a6_coef_structure.*` — L1 先删掉哪些系数

**画的是什么**：左 = truth L20 在三个 λ1（1e-4、0.01、0.05）下的非零系数幅值分布（log-log 直方图，图例给出非零数：2220 / 217 / 45）；右 = 三条任务的"有效系数数" $(\sum|w|)^2/\sum w^2$ vs λ1/λ1_max（world 按两个输出分别算再平均）。

**关键读数**：
- λ1=1e-4（2220 维）：幅值分布很宽，主峰在 1e-2–1e-1，尾部到 ~0.5；有效系数数 **1377.8**。
- λ1=0.01（217 维）：主峰移到 1e-2 附近，小系数被整段切掉；有效系数数 **107.5**。
- λ1=0.05（45 维）：只剩大系数，分布更窄、幅值整体右移（最大的约 0.3–0.5）；有效系数数 **22.7**。
- 有效系数数曲线：λ1→0 的极限约 **1630**（不是 2560——L2 岭解本身就集中在约 1600 个有效维度上）；λ1=0.1 时 world 1254、L20 10.0、L23 14.4；λ1=1 时 world 472。
- L20 与 L23 的有效系数曲线几乎重合；world 在同一 f 下略高（更稠密）。

**证明了什么**：
1. **L1 是"从最小的系数开始切"**：三个直方图的左边界随 λ1 增大而右移，被删掉的是小幅值系数，大系数保留并继续被收缩——与软阈值的几何一致。
2. **"非零数"和"有效系数数"是两套刻度**：L20 在 λ1=0.01 时非零 217、有效 107.5；非零数高估了实际参与预测的维度数约一倍。报告里如果只说"非零数"，会显得比实际更稠密；两个指标应一起报。
3. **极限有效维度 ~1630**：即使 λ1→0，L2 岭解也只在约 1600 个方向上有实质权重，说明"稠密"不是 2560 个等权方向，而是"约 1600 个有效方向 + 长尾"。这为"superposition/分布式表征"的叙述提供了一个更准确的数字。

**报告怎么用**：A6 的机制图。左 panel 用于解释"L1 剪小系数"；右 panel 用于把"非零数"翻译成"有效自由度"。如果报告篇幅有限，右 panel 比左 panel 更值得放（它直接支撑"有效维度"的叙述）。
图注候选（中文）：*"A6：L1 剪掉的系数结构。左：truth L20 在 λ1=1e-4/0.01/0.05 下的非零系数幅值分布（2220/217/45 个非零）。右：有效系数数 $(\sum|w|)^2/\sum w^2$ 随 L1 强度的变化；λ1→0 的极限约 1630，说明 L2 岭解本身的有效维度约 1600，而非 2560。"*
图注候选（English）：*"A6: what L1 removes. Left: magnitude distributions of the nonzero truth-L20 coefficients at λ1=1e-4/0.01/0.05 (2220/217/45 nonzeros). Right: effective number of coefficients $(\sum|w|)^2/\sum w^2$ versus L1 strength; the λ1→0 limit is about 1630, so even the L2 ridge solution effectively uses about 1600 rather than all 2560 dimensions."*

## 4. 结论、caveats 与报告写法

### 4.1 可以直接写进报告的结论

1. **表征是稠密的，但可稀疏化**：50% 维度归零只需 λ1/λ1_max≈**0.013（world）/0.0034（L20）/0.0039（L23）**；90% 归零需要 **0.107/0.039/0.050**。在 λ1=0.01 时，world 仍保留 **2559/2560** 维，而 truth 只剩 **217–241/2560** 维（8.5%–9.4%）。
2. **"L1 全程有害"不复现**：在本协议下，world valid MSE 有 **−0.76%** 的浅收益（165.90 vs 167.17）；truth L20 valid acc **+2.33pp**（89.00% vs 86.67%，217 维）、logloss **0.2948 vs 0.4835**；truth L23 logloss **0.3150 vs 0.4865**（562 维），acc **+1.33pp**（86.33%，1111 维）。**温和 L1 有益、强 L1 有害**，可用区间窄（truth λ1≲0.03，world λ1≲0.3）。
3. **有效维度 ~1630（L2 极限）**：非零数 2560 是上限；按 $(\sum|w|)^2/\sum w^2$ 计，L2 岭解的有效系数数约 **1630**，L20 在 λ1=0.01 时约 **108**、λ1=0.05 时约 **23**。报告里区分"非零数"和"有效数"能避免把长尾小系数算成有效容量。
4. **求解器选择影响结论**：`model.py` 的 `sign()` 次梯度在 λ1=0.01 时仍有 **5120/5120** 个非零条目（5109 个 >1e-6），且 train MSE 92.93 高于近端解的 92.09；做 L1 密度统计必须用近端/坐标下降，不能直接用 `sign()` 的结果。

### 4.2 Caveats（写报告时必须带上）

- **valid 只报告、未用于选型**：L20 的 89.00% 是 valid 曲线上的一个点，不是"选中"的模型；真实选型应在 train 内 CV（A7），否则会乐观。+7/300 条的差异未做配对显著性检验，不要写"显著提升"。
- **λ2 固定为 A1 锚点**：λ1 与 λ2 的交互未扫描。换 λ2 会同时改变 λ1_max、密度曲线和最优 λ1；本实验回答的是"在课程锚点 λ2 下加 L1 会怎样"。
- **λ1_max 的口径**：定义为"w=0 最优的最小 λ1"，按截距-only 解处的平滑梯度最大值计算（world 取两个输出的最大）。它依赖特征缩放（z-score）与 λ2，不能和指南的绝对 λ1 直接比较。
- **world 的 nonzero 是"行"**：二维输出下按"至少一个输出非零"计；条目数在 λ1=0.01 时是 5119/5120。报告里引用"2559"时要说明是维度数，不是条目数。
- **边界点的数值伪影已修正**：λ1=λ1_max 时 truth 的 p≈0.5，浮点噪声会让 `p>=0.5` 随机判类；本脚本把概率四舍五入到 1e-12 后再判类，边界 acc 记为 50%、logloss=log 2。原始 0.693/0.74 的读数是伪影，不要引用。
- **单 split、n=300 valid**：truth 的百分比粒度是 1/300≈0.33pp；L20 的 89.00% vs 86.67% 只差 7 条样本，L23 的 86.33% vs 85.00% 只差 4 条。**统计功效有限**。
- **FISTA 收敛判据**：相对目标变化 <1e-7（40 步窗口），全部记录 converged=True；但最小 λ1 的解仍可能有 ~1e-6 量级的系数残差（`nonzero_1e-6` 略低于 `nonzero`），不影响密度结论。

### 4.3 与指南1 §4.3.2 的对照

- 指南的"λ1=0.01 时仍有 1860 个非零系数"是在其数据/λ2/层上的读数；我们的同 λ1 读数是 **world 2559、L20 217、L23 241**。**同一个绝对 λ1 不能跨任务比较**，必须带 λ1_max 或 f。
- 指南的"L1 全程有害"在本协议下**不成立**：truth 的 mild-L1 点同时改善 acc 和 logloss。差异的可能来源：① 指南的 λ2 与特征缩放不同；② 指南用 `sign()` 次梯度，非零集合与近端解不同；③ 指南的评估层/任务不同。报告里应写成"**在我们的协议下不复现**"，并给出 λ1_max 归一化后的曲线，而不是断言指南错。
- 指南"L1 次梯度在 0 点振荡、永远得不到精确零"被 §0.4 直接复现：5120/5120 条目非零，5109 个 >1e-6。

### 4.4 报告用法建议

- **正文"表征稠密性"小节**：放 `a6_density_curves` + 50%/10% 两个锚点；一句话结论："50% 维度归零只需 0.3%–1.3% 的 λ1_max，90% 需要 3.9%–10.7%。"
- **正文"正则化"小节**：放 `a6_metric_vs_l1`，明确写"温和 L1 小幅有益、强 L1 迅速有害；valid 峰值仅作描述，不作选型"。
- **附录/机制讨论**：放 `a6_coef_structure`，用有效系数数 ~1630 支撑"分布式/叠加表征"的叙述；同时给出 `sign()` vs 近端的求解器对比（§0.4）。
- **不要写**：不要写"L1 无用/有害"或"L1 显著提升"；不要把 2559（world 维度数）与 5119（条目数）混用；不要把 λ1=0.01 的绝对值和指南的 1860 直接对比；不要把 valid 峰值当成选型结果。
