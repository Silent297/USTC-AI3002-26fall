# 学习率稳定界（全批量 GD）：怎么找的

回答一个问题：`train_layers.json` / `hparam_grid*.json` 里那些「稳定界」数字（world 未标准化
5.4e-4、标准化后 3 ~ 5e-3……）是怎么来的？结论：**不是试出来的，是从特征矩阵的谱直接算出来的**
（`lr < N/‖X‖₂²`），再用训练实验双向验证过。

## 1. 为什么需要这个界

`world` 任务在未标准化特征上，lr 稍大就梯度溢出（`loss=inf`），且深层比浅层更容易炸
（88653 扫描：layer 23/35 在 lr=2e-4 下发散）。这不是「深层没信息」，而是全批量梯度下降
在一个**病态二次曲面**上迭代的纯数值问题。要用同一把尺子比较各层，就必须先知道每层
「lr 最多能取多大」。

## 2. 理论：界从哪来

`world` 用均方误差 `L = ‖Xw + b − y‖² / N`（N 为训练样本数，梯度 `2Xᵀr/N`，与
`model.py` 一致）。这是一个凸二次函数，Hessian：

```
H = 2 XᵀX / N
```

梯度下降的误差传播为 `e_{t+1} = (I − lr·H) e_t`（`e = w − w*`），收敛 ⇔ 谱半径 < 1：

```
ρ(I − lr·H) < 1  ⇔  0 < lr < 2 / λmax(H) = N / ‖X‖₂²
```

其中 `λmax(XᵀX) = ‖X‖₂²`（最大奇异值的平方，也即 Gram 矩阵最大特征值）。
**这就是「稳定界」**：只依赖特征矩阵 X（与 y 无关），每层单独一个值。越界后在最大特征
方向上误差每轮乘以 `|1 − lr·λmax(H)| > 1`，指数放大，直到溢出成 inf。

`truth` 用 logistic 损失，Hessian 为 `Xᵀ diag(p(1−p)) X / N ⪯ XᵀX / (4N)`，
最坏情形（p=1/2）的充分稳定界放宽到约 `8N/‖X‖₂²`（≈ 二次界的 8 倍）。
更重要的是 logistic 的梯度有界（`p − y ∈ [−1,1]`），没有 MSE 那种「残差随 w 线性增长」
的正反馈，所以**越界一般表现为震荡/饱和、准确率下降，而不是爆炸**——这正是 truth
可以不标准化、直接用 raw 特征 + lr=0.005 的原因（88653 中 lr=0.01 仍有限，只是准确率
掉到 0.63；而 world 在 lr 越界时是直接 inf）。

## 3. 怎么算

对每层 train split 的特征矩阵：

1. 直接算 `‖X‖₂²`（= 第一奇异值平方，本仓库用 `np.linalg.norm(x, 2) ** 2`，SVD 精确值，
   不用幂迭代近似）；
2. 稳定界 = `N / ‖X‖₂²`，N = 该任务训练集行数（world 500、truth 5088）；
3. 标准化版本用 train split 的 μ/σ 做 z-score 后再同理计算（与 `run_grid.py` 的口径一致，
   μ/σ 只看 train，不泄漏验证集）。

脚本已入库，一条命令复现下表（本机约 2.5 分钟，纯 numpy）：

```bash
python experiments/stability_bound.py                 # 全部 13 层 × 两任务
python experiments/stability_bound.py --layers 11,23,35
```

此前的数字（报告 §8.2 里 layer 11/23/35 的 5.4e-4 / 8.4e-5 / 2.8e-6 和 3.6e-3 / 3.2e-3 / 4.8e-3）
与本脚本的输出逐位一致。

两点观察：

- **raw 界随深度暴跌**（world 三层从 4.95e-3 到 2.77e-6，跨 1800 倍）——激活幅度逐层增大
  （残差流范数 51 → 623，约 12 倍；平方进 ‖X‖₂² 就是两个数量级），固定 lr 必然在深层越界。
- **z-score 把界「拉平」**：全部压到 3.1 ~ 4.8e-3（仅 1.5 倍差距）。z-score 只归一化每列尺度，
  保留下来的差异来自特征间的相关结构。正因为拉平了，**同一个 lr 才能对所有层公平**。
- truth raw 界同样随深度缩，但如上节所述 logistic 对越界是「软」的，所以 truth 组不依赖它。

## 5. 实测验证（对拍）

理论界与实际训练行为逐条吻合（stable = 有限收敛，炸 = loss 溢出/爆炸）：

| 配置 | 界的值 | 界内实测 | 界外实测 |
| --- | --- | --- | --- |
| world raw L11 | 5.4e-4 | lr=5e-4 稳定（贴线，MSE 150.9） | lr=1e-3 → 直接溢出 |
| world raw L23 | 8.4e-5 | — | lr=2e-4（×2.4）→ 收敛前爆炸 |
| world raw L35 | 2.8e-6 | — | lr=2e-4（×72）→ 71 轮即炸 |
| world std L11 | 3.6e-3 | lr=3e-3（×0.83）→ 167.06 | lr=5e-3（×1.39）→ 发散（89085，~600 轮） |
| world std L23 | 3.2e-3 | lr=3e-3（×0.95）→ 241.12 | — |
| world std L35 | 4.8e-3 | lr=4e-3（×0.84，冒烟 300 轮 MSE 204.7） | lr=8e-3（×1.68）→ 第 9 轮 loss 爆炸 |
| truth raw L35 | （1.7e-6，logistic 界宽松） | lr=5e-4 → 有限（acc 63.0%），无爆炸 | lr=5e-4 已超二次界 ~300 倍，仍有限：logistic 非爆炸性 |

## 6. 这个界怎么用于选 lr

- `train_layers.json` 里 world 统一用 z-score + `lr=0.002`：对最紧的 13 层实测界（L5，3.08e-3）
  留有 **1.54 倍余量**，对最松的 L35 有 2.4 倍余量；也远低于 L11 上 0.001~0.003 的「平台区」
  （该区间 MSE 差异在噪声内）。
- 兜底：`train_layers.py` 的 lr 回退机制（发散则 lr×0.5 重试 ≤4 次）处理任何理论之外的情况；
  发散检测用「loss > 初始 loss 的 1e6 倍」而非等 inf（发散晚期才会到 inf，早期到不了）。
- 更换特征口径（token、dtype、新层）后界会变——重跑 `stability_bound.py` 即可，不必再用训练试错。
