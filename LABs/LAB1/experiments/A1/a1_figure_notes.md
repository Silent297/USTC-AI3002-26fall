# A1 逐图解释说明（多层拼接线性探针）

> 实验：`experiments/A1/` —— 拓展实验 A 系列之一（附加探究，非课程必交内容）。把单层线性探针推广到**多层特征拼接**，回答"线性读出头是否够用、信息在哪些层、哪些层组合最有用"。
> 协议：13 层 {2,5,8,11,14,17,20,23,26,29,32,34,35}；每层在 train 上 z-score，拼接 = 各层**独立 z-score 后 concat**（维度 = 层数 ×2560）。world（500/130，回归，valid MSE 度²）主口径 = **闭式对偶 ridge 固定 λ2=1.0**（零选择偏差，与历史 std 协议同预算）；副口径 = RepeatedKFold(5×4) 训练内部 CV 选 λ。truth（5088/300，分类，valid acc）用 lbfgs 固定 C=1/(2Nλ2)、λ2=1e-3。组合 = 13 单层 + 78 对 + 6 组固定三元组 → world 97 / truth 91 个拟合。
> 锚点（口径闭环）：world z L11 单层 λ2=1 → **167.1707**、L2 → **157.6186**（与 Q3 sklearn 行逐位一致）；历史提交 raw L11 → 150.43；truth 历史 GD raw L20 → 0.8967。参考报告（非官方）：KNN 125.27 / MLP-128-64 152.70。
> 读数与复现：`a1_run.log`、`a1_results.json`（97+91 组合全量）；`python experiments/A1/a1_multilayer_concat.py`（2884 s，2026-10-16）。
> 维护约定：每完成一批绘图，在实验目录下新建 `aX_figure_notes.md`，格式同本文与 `question/figures/q8_figure_notes.md`。

## 总览

| 图 | 一句话 | 回答的内容 |
|---|---|---|
| `a1_concat_heatmaps` | 13×13 配对热图（对角线=单层、下三角=拼接；左 world MSE、右 truth acc） | "哪些层组合有用/没用" |
| `a1_best_combos` | top-8 对 + top-3 三元组 vs 最好单层与历史锚点 | "拼接比单层好多少" |
| `a1_corr_matrices` | 单层探针跨层**残差**相关矩阵（预测相关均值：world 0.980、truth 0.521） | "为什么拼接有用/为什么 truth 收益小" |

一句话主线：**拼接在两任务上都有收益，但收益结构完全不同**——world 要"早层 × 深层"组合（L5+L32 **128.82**，比最好单层 157.62 低 18%，也低于历史提交 raw L11 的 150.43）；truth 中深层之间组合最强（L17+L20 **0.8833**，+1.7pp）。world 各层预测高度冗余（相关 0.980）、收益来自误差互补；truth 层间预测相关仅 0.521 但早层太弱（L2 单层 0.590），只有深层间组合才是有效增量。

## 1. `a1_concat_heatmaps.*` — 配对热图

**画的是什么**：左 = world：矩阵 (i,j) 下三角 = Li+Lj 拼接的 valid MSE、对角 = 单层（z-score、λ2=1.0），上三角留白；右 = truth 同结构（valid acc）。

**关键读数**（2026-10-16 全量）：
- **world 最优 = "早层 × 深层"**：L5+L32 **128.82** ＞ L2+L32 **131.47** ＞ L8+L32 **134.35**（前三名都含 L32）；其后 L2+L35 142.06、L5+L34 143.11、L5+L35 143.67、L8+L29 143.9。单层最优 L2 = 157.62（中位点距 977.5 km）；L5+L32 中位点距 **800.4 km**。78 对中 **21 对**优于最好单层。
- **world 中段配对反而劣于单层**：L14–L26 互相组合 173–196——不是"多拼就好"。
- **truth 最优 = 中深层组合**：L17+L20 **0.8833**、L17+L26 **0.8833**；L14+L20 / L17+L29 / L20+L29 0.8767。单层最优 L20 0.8667（L23 0.85、L17 0.8333）；早层单层很弱（L2 0.590 / L5 0.623 / L8 0.680 / L11 0.717）。78 对中 **6 对**优于最好单层。

**证明了什么**：
1. 拼接对两任务都有效：world 最好配对比最好单层低 **28.8 MSE（−18%）**，且低于历史提交探针（150.43，raw L11）；truth +1.7pp——且都是**线性**探针（更高维线性模型），提升来自"表征层组合"而非非线性。
2. 组合有清晰的层结构而非噪声：world 的"早层细节 × 深层语义"、truth 的"中深层互补"在热图上呈成片条带/区块。
3. 稳健性：副口径（train 内部 RepeatedKFold(5×4) 选 λ）下 L5+L32 = 139.56（λ*=3）仍优于所有单层；主口径固定 λ2=1.0 完全排除"用 valid 挑配置"的偏差（本文一律引用主口径）。

**报告怎么用**："线性读出上限"论证的第一证据——引 top 组合 + 一句"早×深 / 中深结构"；呼应 Q4 选层（单层选 L2/L20，拼接可再显著提升）。
图注候选（中文）：*"A1：层对拼接的验证指标矩阵。左：world（valid MSE，z-score、λ₂=1.0），对角为单层、下三角为 Li+Lj 拼接，最优组合集中在'早层 × 深层'（L5+L32 = 128.8，比最好单层低 18%）；右：truth（valid acc），最优为中深层组合（L17+L20 = 0.883）。"*
图注候选（English）：*"A1: pair-concat validation metrics. Left: world (valid MSE, z-scored, λ₂=1.0); diagonals are single layers, lower triangle are Li+Lj concats — early × deep pairs win (L5+L32 = 128.8, −18% vs best single layer). Right: truth (valid acc); mid-deep pairs win (L17+L20 = 0.883)."*

## 2. `a1_best_combos.*` — 最优组合 vs 单层与锚点

**画的是什么**：左 world、右 truth；蓝条 = top-8 配对，橙条 = 6 组固定三元组中的前 3；虚线 = 本协议最好单层（158 / 0.867）；点红线 = 历史锚点（raw L11 提交 150.43 / GD raw L20 0.8967）。

**关键读数**：world top-4 对 **128.82 / 131.47 / 134.35 / 142.06 全部低于历史提交锚 150.43**；三元组最好 L2+L11+L35 **140.17**（三元组表只测 6 组固定组合、未穷举）。truth 最优对 0.8833 高于单层锚 0.8667，但仍低于 GD raw L20 0.8967（raw+GD 协议与本文不同，作历史参照线）。

**证明了什么**：① 拼接收益量级明确——world 上对/三拼接都能越过历史提交与 guide 之外的其它锚点（L5+L32 与 guide KNN* 125.27 仅差 3.5）；② truth 拼接增益温和（+1.7pp，且未到 GD raw 线），说明分类任务上单层 L20 已抓住大头。

**报告怎么用**：结论句"两/三层线性拼接即可超过所有单层方案（含历史提交）"的配图。

## 3. `a1_corr_matrices.*` — 跨层相关矩阵（机制）

**画的是什么**：左 world、右 truth；颜色 = 单层探针在 valid 上**残差**（pred − truth）的跨层相关；标题给出**预测**相关均值（world **0.980**、truth **0.521**）。

**关键读数**：world 单层预测彼此相关均值 0.980（几乎同向、高度冗余），残差在相邻层呈块状高相关；truth 预测相关仅 0.521（层间信息更分化）。

**证明了什么**：world 各层编码高度冗余的地理信息——解释了 (a) 单层曲线 L2–L11 的宽平台（157–167）；(b) 拼接增益只能来自小量互补分量（误差相消）却依然可观（−18%）。truth 层间更分化，但早层质量太差（0.59–0.72），只有中深层之间才有可组合的互补信号。

**报告怎么用**："拼接为什么有用"的机制解释小图；与 Q4 单层曲线互引。
