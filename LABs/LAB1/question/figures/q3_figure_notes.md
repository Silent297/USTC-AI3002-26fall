# Q3 逐图解释说明

> 题目：你的模型相比于 sklearn 的实现有拟合效果上的差异吗？
> 本文档逐图记录 3 张 `q3_*` 图：**画的是什么 / 关键读数 / 证明了什么 / 报告怎么用**，供写 LaTeX 报告时直接取材。
> 读数口径：ours 目标 = (1/N)·loss + λ1‖w‖₁ + λ2‖w‖²₂，换算处已对齐（Ridge α=N·λ2；Lasso α=λ1/2；ElasticNet αρ=λ1/2、α(1−ρ)=λ2；逻辑回归 C=1/(2Nλ2)，truth N=5088、λ2=1e-3 → C≈0.098）。最终指标用仓库 `model.py` 的真实实现；收敛曲线用与其更新式完全一致的仪器化副本（不改动提交代码）。全部数字取自 run 2 运行日志。
> 维护约定：每完成一批绘图，在 `figures/` 下新建一份 `<题号>_figure_notes.md`，格式同本文与 `q2_figure_notes.md`。

## 总览：三张图的叙事链

| 图 | 一句话 | 回答的"差异来源" |
|---|---|---|
| `q3_convergence` | 有限轮 GD 停在离最优还有距离的点上 | ② 收敛预算 ≈ 隐式正则 |
| `q3_weight_parity` | 对齐口径后权重落在对角线上（充分收敛时） | ① 优化差异，不是模型差异 |
| `q3_valid_bars` | valid 指标逐配置对比 + 发散红叉 + C=1 参考线 | ① 步长机制 ② 早停正则 ③ 口径 |

一句话主线：**没有本质差异**——差异是"优化差异"（步长/求解器/预算/早停），不是"模型或实现差异"。

## 1. `q3_convergence.*` — 收敛曲线（差异来源②：预算）

**画的是什么**：左 panel = world L11（z-score、无正则）GD 全批量训练曲线，纵轴 train MSE（log 刻度，lat 单坐标），横轴 epoch（lr=2e-3，20000 轮）；右 panel = truth L20（raw、λ2=1e-3）GD 训练曲线，纵轴 train logloss（lr=5e-3，5000 轮）。

**关键读数**：
- 左：曲线从 ~1e3 量级缓慢下滑，20000 轮终值 **0.0047**；黑色虚线 = sklearn 精确 LS 的 train MSE = **0**（log 轴上 0 画不出来，抬到 1e-12 位置示意）。
- 右：前 ~100 轮陡降（~1 → 0.3），随后长尾缓降，5000 轮终值 **0.18141**；黑虚线 = sklearn lbfgs l2（C≈0.098）train 最优 **0.06560**；灰点线 = penalty=None train 最优 **0.00000**。

**证明了什么**：
- world 是 p≫n 病态问题（2560 特征 / 500 样本）：精确解 train MSE=0，但 GD 20000 轮只走到 0.0047、离 0 还很远——**白盒 GD 的"有限预算"天然停在更小范数的点**，这正是它 valid 反而好于精确 LS 的原因（A1：306.55 < 311.56）。
- truth 同理：GD 停在 0.181（未到 l2 最优 0.066），valid 反而更好（T2：ours 0.8867 > sk 0.8600）；而 penalty=None 的"最优"train logloss=0 意味着参数沿可分方向跑向无穷远（T1 的 valid 对数损失 27.77 灾难）。

**报告怎么用**：配"预算=隐式正则"论点。图注候选：*"world（p≫n 病态）GD 20000 轮仅到 0.0047（精确 LS=0）；truth GD 5000 轮停于 0.181，未达 lbfgs 最优 0.066——有限预算 GD 天然早停、起正则化作用。"*

## 2. `q3_weight_parity.*` — 权重一致散点（差异来源①：同解验证）

**画的是什么**：三个面板，横轴 = sklearn 权重、纵轴 = ours 权重，黑色虚线 = 对角线（完全一致）；每个面板标注 cos 与 relL2（两坐标权重拼接后与 sklearn 的相似度）。面板分别为 A1（world z，无正则）、A2（world z，λ2=1.0 ≈ Ridge α=500）、T2（truth，λ2=1e-3 ≈ C=0.098）。

**关键读数**：
- A1（no reg）：cos **0.9993**、relL2 **0.039** —— 点云紧贴对角线、略有可见散布（GD 未完全收敛到精确 LS）。
- A2（l2=1.0）：cos **1.00000**、relL2 **0.002** —— 几乎完美对角线：**同一目标函数 + 充分收敛 ⇒ 同解**。
- T2（truth l2）：cos **0.8024**、relL2 **0.794** —— 点云整体被压向 0（y 幅度 ≪ x）：GD 5000 轮停在更小范数点，lbfgs 在可分方向上继续跑远。

**证明了什么**：
- 第 2 面板是整个 Q3 的"锚"：口径对齐后，两者解在同一位置——差异之谜被锁到"求解过程"上。
- 第 3 面板给出差异的形态：**沿范数大小被压缩**（早停的隐式正则效应）；继续训练会向 sklearn 靠拢（T2b ep10000：cos 0.80→**0.883**），但 valid 可能回落（T2b 0.8733 < T2 0.8867）——预算大小本身就是在调一个正则强度。

**报告怎么用**：正文主图（"无本质差异"的直接证据，第二面板）。图注候选：*"对齐正则口径后，world（λ2=1.0）权重逐点落在对角线上（cos=1.00000）；truth 未充分收敛时权重整体压向 0（relL2=0.794）——差异沿'收敛程度'而非'模型'。"*

## 3. `q3_valid_bars.*` — valid 指标条形（三种来源总览）

**画的是什么**：左 = world raw L11 的 valid MSE（红 ours / 蓝 sklearn，3 组配置 + 第 4 组红叉 = 发散演示）；右 = truth raw L20 的 valid 准确率（3 组配置 + 灰色点线 = sklearn C=1 参考）。

**关键读数——左（world raw L11，ours 稳定界 ≈5.4e-4）**：
- B1 no reg ep20k：ours **223.58** vs sk **395.02**（ours 好 171）；sklearn 是精确最小范数 LS（train MSE=0）、valid 却差——p≫n 下插值解泛化差。
- B2 best cfg ep2k：ours **150.43** vs sk **165.34**（= 历史最优锚点）。
- B2b best cfg ep20k：ours **162.36** vs sk 165.34——延长训练向 sklearn 靠拢（cos 0.897→0.997），valid 反而略降（150.4→162.4）。
- 第 4 组红叉：lr=1e-3 超过稳定界 ≈5.4e-4 → 第 8 轮 loss 爆炸（1.14e10 vs 初始 2.4e3）自动停——**固定步长 GD 的机制性限制，精确求解器（sklearn）没有**。

**关键读数——右（truth raw L20）**：
- ours no reg：**0.8867** vs sk（penalty=None）0.8533；
- ours l2=1e-3：**0.8867** vs sk（C≈0.098）0.8600；
- ours best cfg（λ1=λ2=1e-3）：**0.8967** vs 0.8600（T3 = truth 训练报告锚点）；
- 灰点线：sklearn **C=1**（默认、更强的正则）→ valid **0.8500**——口径不对齐时会把"超参不同"误读成"实现差异"。

**证明了什么**：三行结论各占一个位置——① 步长机制（红叉）；② 预算=隐式正则（左三组的 ours≤sk 差距与 B2→B2b 反转；右三组 ours 全面不低于 lbfgs）；③ 口径（C=1 参考线）。整体印象：ours 不劣于 sklearn，差异为几个百分点且方向与"早停正则"一致。

**报告怎么用**：Q3 收尾总览图。图注候选：*"world raw：GD 早停的 valid 223.6 ≪ 精确 LS 的 395.0；lr=1e-3 超稳定界第 8 轮即发散（红叉）。truth：ours 全面不低于 lbfgs；C=1 线示口径不对齐的陷阱。"*
