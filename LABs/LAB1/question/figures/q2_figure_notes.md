## 1. `q2_corr_matrix.*` — 相关矩阵（前提图）

**画的是什么**：9 个特征两两 Pearson 相关，RdBu 色标（−1..1），格内标注两位小数。

**关键读数**：
- 主共线块：`sqft_living ~ sqft_above` **0.88**（精确 0.876）——最强对；`bathrooms ~ sqft_living` 0.76（精确 0.756）；`bathrooms ~ sqft_above` 0.69；`bedrooms ~ sqft_living` 0.58。
- 次级相关：`floors ~ sqft_above` 0.52；`bathrooms ~ yr_built` 0.51；`floors ~ yr_built` 0.49；`yr_built ~ yr_renovated` −0.22（负相关）。
- 近无关：`sqft_lot`、`waterfront` 与其余特征大多接近 0。

**证明了什么**：{living, above, bathrooms, bedrooms} 构成一个相关块、{floors, yr_built} 一个弱块。**相关（≠相等）意味着共线方向上权重可以"平摊/互换"而几乎不改变拟合**——这是后面所有现象的土壤，也是 p45 "相关特征在 ridge 下同时收缩 → 阈值化整组删除" 的前提。`sqft_lot`/`waterfront` 的抖动则属于另一类（近独立特征自身的阈值敏感性）。

**报告怎么用**：放机制段之前的铺垫图（或移入附录）。图注一句：*"9 特征相关矩阵：living/above/bathrooms/bedrooms 构成相关块，为共线平摊提供条件。"*

## 2. `q2_ridge_band_path.*` — 路径 + 阈值带 + 保留计数（现象图）

**画的是什么**：上 panel 为 9 条 ridge 系数路径（λ: 0→2e5），粉色虚线带 |w|<1e4 表示"视为 0"，灰色虚线 λ=2e4 为故事点；下 panel 为保留计数 step 曲线（红=ridge 阈值化，蓝=lasso 非零）。

**关键读数**（精确值，单位：美元/σ）：

| 特征 | λ=0 | 1e4 | 2e4 | 5e4 | 1e5 | 2e5 |
|---|---|---|---|---|---|---|
| sqft_living | +254,489 | +113,545 | +86,578 | +55,186 | +35,983 | +21,635 |
| sqft_above | +15,934 | +68,222 | +59,449 | +42,302 | +29,005 | +17,984 |
| bathrooms | +51,237 | +53,950 | +46,496 | +34,121 | +24,055 | +15,219 |
| bedrooms | −56,730 | −4,588 | +7,065 | +13,035 | +11,550 | +8,111 |
| floors | +24,584 | +10,211 | +11,315 | +11,470 | +9,520 | +6,643 |
| yr_built | −93,985 | −49,474 | −30,643 | −11,386 | −3,685 | −572 |
| yr_renovated | +3,324 | +13,649 | +13,998 | +10,665 | +7,091 | +4,176 |
| waterfront | +63,515 | +51,172 | +41,127 | +25,733 | +15,893 | +9,039 |
| sqft_lot | −13,069 | −1,655 | +1,752 | +3,685 | +3,332 | +2,355 |

（λ=0 列为 9 特征最小二乘解，与 Q1 的 8 特征模型数值不同，属正常。）

三个关键现象：
1. **无一归零**：所有路径只缩不归零，λ=2e5 时最小的 `yr_built` 还有 −572——"小 ≠ 不重要"（p48）。
2. **路径不单调、与带反复相交**：`sqft_above` 从 1.6e4 涨到 6.8e4（λ≈1e4）再回落（living 被压时它"接棒"拿权重）；`bedrooms` 从 −5.7e4 在 λ≈1.5e4 穿过 0 变正；`yr_renovated` 在 λ=0 时只有 +3.3e3（**在带内，按阈值"该删"**），随 λ 增大反而涨进带外被"选上"，λ≈5.6e4 又落选。
3. **与带的关系分三类**：`sqft_living`/`sqft_above`/`bathrooms` 全程在带外；`waterfront` 撑到 1.77e5；其余五个特征各自在不同 λ 出带、回带。

**下 panel 保留计数**：
- ridge（红）：**8→7→8→7→6→7→8→7→6→5→4→3**，沿 λ 跳变 **11 次**、含 **3 次"回升"**（λ=4k `yr_renovated` 入队、9k `floors` 回归、27k `bedrooms` 回归）；
- lasso（蓝）：非零数 **9→1 严格单调**，零次回升。

**证明了什么**：阈值化 ridge 的"选择路径"连单调性都不满足，不具备"路径"的语义；lasso 才有（p44/49 的对照可视化）。

**报告怎么用**：正文讲"沿 λ 的不稳定性"的主力图，配 p44。图注一句：*"τ=1e4 时 ridge 保留集沿 λ 跳变 11 次（含 3 次回归）；lasso 零模式严格单调。"*

## 3. `q2_selection_matrix.*` — 选择矩阵（结构对照图）

**画的是什么**：左=ridge 阈值化（|w|>1e4）在选择矩阵中的"在选窗口"（蓝=在选）；右=lasso 零模式（蓝=非零）。

**关键读数——ridge 在选窗口**（精确，τ=1e4）：

| 特征 | 在选窗口 (λ) | 备注 |
|---|---|---|
| sqft_living / sqft_above / bathrooms | [0, 2e5] | 全程在选 |
| waterfront | [0, 1.77e5] | λ=1.78e5 落选 |
| yr_built | [0, 5.4e4] | |
| bedrooms | [0, 7e3] ∪ [2.7e4, 1.38e5] | **离开后回归** |
| floors | [0, 5e3] ∪ [9e3, 8.7e4] | **离开后回归** |
| yr_renovated | [4e3, 5.6e4] | λ=0 时反而"不在选" |
| sqft_lot | [0, 1e3] | 仅最左一条细条 |

**关键读数——lasso 归零 λ\***（每个特征恰一段连续非零窗口 [0, λ\*]）：

| 特征 | λ\* | 特征 | λ\* |
|---|---|---|---|
| sqft_lot | 10k | floors | 23k |
| yr_renovated | 13k | bathrooms | 26k |
| sqft_above | 17k | yr_built | 45k |
| bedrooms | 21k | waterfront | 79k |
| sqft_living | 至 2e5 仍非零（57.7k @2e5） | | |

**证明了什么**：嵌套 ⇒ 复杂度由单一超参数 λ 控制、可选模型是"从右往左的阶梯"；**非嵌套 ⇒ 同一特征离而复返，"更大 λ = 更小模型"的语义崩塌**。这是对 p44 批评的结构化复现。

**报告怎么用**：正文主图之一（结构判据）。图注候选：*"τ=1e4 时 ridge 保留集沿 λ 跳变 11 次（bedrooms、floors 离开后回归），不嵌套；lasso 零模式严格嵌套，每特征仅一个连续非零窗口 [0, λ*]。"*

## 4. `q2_collinear_case.*` — 共线案例（机制图）

**画的是什么**：左=真实数据（λ=2e4）下"单独 vs 成对"的 ridge 系数对比，粉色虚线 τ=1e5；右=合成复制特征（x2≡x1，λ=2e4）下 ridge 与 lasso 的系数对比，粉色虚线 τ=1e5。

**关键读数**：
- 左：`sqft_living` 单独 ridge = **133,791**；加入兄弟 `sqft_above` 后 = **86,578 + 59,449 = 146,027**（≈对半切，组合与≈单特征值）。τ=1e5 下：单独时 133,791 > 1e5 **保留**；成对时两个都 < 1e5 → **整组被删**。
- 右：复制特征时 ridge 精确对半 **(88,067, 88,067)**，任何 τ∈(88,067, 176,134) 都会删掉整组；lasso **(237,689, 0)** 保留一个代表、另一个精确 0。
- 彩蛋：右侧 lasso 的 237,689 与真实数据 lasso@2e4 的 `sqft_living`=**238,232** 几乎相同——说明真实的 living/above 对近似"复制特征"，左右两 panel 互相印证。

**证明了什么**：共线组内 |wⱼ| 不是重要性、是"分摊系数"（≈组总权重/副本数）；阈值判定强烈依赖特征怎么被编码（多录一列就能把"必选"变"全删"）；lasso 的零来自优化几何，天然给组一个代表。即 p45 "Nothing measuring bathrooms!" 的同款机制。

**报告怎么用**：机制段配 p45。图注一句：*"加入一个共线兄弟即可让每个系数减半、τ=1e5 下整组被删（133,791 → 86,578 + 59,449）；lasso 组内保留一个代表（237,689, 0）。"*

## 5. `q2_bars_story.*` — p43 式截面条图（一图总览）

**画的是什么**：λ=2e4 横截面，9 根系数条 + 粉色阈值带 τ=1e4（复刻课件 p43 的图式）；左 ridge、右 lasso。

**关键读数**（@λ=2e4）：
- ridge（|w|>1e4 判定，**selected 7**）：保留 = bathrooms +46,496 / sqft_living +86,578 / sqft_above +59,449 / floors +11,315 / yr_built −30,643 / yr_renovated +13,998 / waterfront +41,127；带内（被删）= bedrooms +7,065、sqft_lot +1,752。
- lasso（真零判定，**nonzero 6**）：nonzero = bedrooms −3,789 / bathrooms +10,568 / sqft_living +238,232 / floors +4,449 / yr_built −41,583 / waterfront +51,182；精确 0 = sqft_above、sqft_lot、yr_renovated。
- **分歧点（同数据、同 λ）**：`bedrooms`（ridge 删 / lasso 保）、`yr_renovated`（ridge 保 / lasso 精确归零）、`sqft_above`（ridge 保 59,449 / lasso 归零，权重集中到 sqft_living 238,232）。
- 顺势 τ 扫描（同一拟合 λ=2e4）：τ=1e4→**7** 个、2e4→**5** 个、5e4→**2** 个（只剩 living+above）、1e5→**0** 个（"全删"）。

**证明了什么**：同一 λ 下"保留"与"非零"在 3 个特征上互相矛盾——保留判定取决于"你用阈值还是优化出来的零"；τ 稍动选择集就崩，τ 是人为的第二超参数（p43）。

**报告怎么用**：可作 Q2 的"一图讲完"总览图（p43 画风）。图注候选：*"λ=2e4：阈值化 ridge 与 lasso 的保留集在 3 个特征上互相矛盾（bedrooms、yr_renovated、sqft_above）；τ 从 1e4 扫到 1e5，ridge 保留数 7→5→2→0。"*
