\subsection*{1. 复现 $\ell_1$ / $\ell_2$ 系数路径与数据来源}

\textbf{题面：}重现课件（第 42、48 页）中 $\ell_1$、$\ell_2$ 正则化的“系数路径”，并解释数据来源。

\skeleton{结论要点，待扩写}
\begin{itemize}
  \item \textbf{数据来源判定}：课件图的 8 个特征列名（bedrooms、bathrooms、sqft\_living、sqft\_lot、floors、yr\_built、yr\_renovated、waterfront）与 King County 房屋销售数据集列名完全一致 $\Rightarrow$ 判定课件系数路径的数据来源为该数据集（Kaggle \texttt{harlfoxem/housesalesprediction}，CC0）；$y=$ price。本仓库副本已与 OpenML 版本按 \texttt{id} 对拍（仅 23 个缺失单元格口径不同，对拍记录见 §附录~\ref{app:repro}）。
  \item \textbf{预处理}：8 特征 + price，剔除 16 个含缺失行（21613 $\to$ 21597 行）；特征 z-score（依据课件批注 “all features normalized so coeff. on same scale”）；$\lambda$ 网格 $0$–$2\times10^5$ 共 201 点。
  \item \textbf{实现}：Ridge 用 SVD 闭式解并与 sklearn 对拍（$\max|\Delta|\approx10^{-9}$）；Lasso 用坐标下降 + warm start（推导见 §附录~\ref{app:math}）。
  \item \textbf{读数（$\lambda=0$ 最小二乘解，单位 美元/$\sigma$）}：sqft\_living 268\,160、waterfront 63\,307、bathrooms 49\,137、floors 28\,399、yr\_renovated 3\,397、sqft\_lot $-12\,378$、bedrooms $-56\,868$、yr\_built $-92\,382$（与课件量级一致）。
  \item \textbf{$\ell_2$ 行为}：全部系数只缩不归零（课件 p48 批注“所有 $\hat w_j\neq 0$ 但大 $\lambda$ 下都很小”）；bedrooms 与 bathrooms 先升后降（相关特征的补偿效应），与课件曲线形态一致。
  \item \textbf{$\ell_1$ 行为}：归零顺序 $\lambda^*$：sqft\_lot 9k $\to$ yr\_renovated 13k $\to$ bedrooms 21k $\to$ floors 23k $\to$ bathrooms 26k $\to$ yr\_built 45k $\to$ waterfront 79k；sqft\_living 至 $2\times10^5$ 仍非零（57.7k）——“只剩一个特征”，对应课件 p49 “only features in our model”。
  \item \textbf{结论}：复现的趋势与量级与课件一致（个别系数有小差，源于数据版本/预处理细节）。
\end{itemize}

\subsection*{2. 用案例说明 $\ell_2$ 阈值化做特征选择为什么不好}

\textbf{题面：}请用案例说明 $\ell_2$ 正则化在回归中将很小的系数设为 0 进行特征选择是不好的（相比 $\ell_1$ 正则化，课件第 44 页）。

\skeleton{结论要点，待扩写}
\begin{itemize}
  \item \textbf{数据}：King County 取 9 特征（Q1 的 8 列 + sqft\_above，与 sqft\_living 相关 $r=0.876$）；z-score + price 中心化；主阈值 $\tau=10^4$（美元/$\sigma$）。
  \item \textbf{① 选择高度依赖阈值 $\tau$}：同一拟合（$\lambda=2\times10^4$）下 $\tau=10^4\to5\times10^4\to10^5$，选中特征数 $7\to5\to2\to0$（$\tau=10^5$ 时“全删”）；沿 $\lambda$ 看保留集跳变 11 次、含 3 次回归（bedrooms、floors 离开后又回归；yr\_renovated 在 $\lambda=0$ 反而在带内）——而 lasso 零模式严格嵌套（违例 0 次）。
  \item \textbf{② bootstrap（40 次半样本）}：边界特征 yr\_renovated 仅 92\% 保持选中；$\tau=10^5$ 下 40/40 全“选空”。
  \item \textbf{③ 共线平摊 $\to$ 整组删除（核心机制）}：sqft\_living 单特征 ridge$(\lambda=2\times10^4)$ 系数 133\,791；加入兄弟特征 sqft\_above 后为 86\,578 + 59\,449（$\approx$ 对半切，和 $\approx$ 单特征值）。$\tau=10^5$：单特征模型保留、成对模型两个成员都被删 $\Rightarrow$ 整个 living-area 组从“必选”变“全删”。合成复制特征（$x_2\equiv x_1$）下 ridge 精确对半 $(88\,067,\,88\,067)$，任何 $\tau\in(88\,067,\ 176\,134)$ 都删整组；lasso 保留一个代表 $(237\,689,\,0)$。
  \item \textbf{④ 预测代价}（train/valid 7:3，按选中特征重拟合 OLS 的 valid $R^2$）：全 9 特征 0.5972；$\tau=10^4$（7 特征）0.5806；$\tau=5\times10^4$（2 特征）0.5032；$\tau=10^5$（0 特征，常数模型）$-0.0003$；对照 lasso@$10^5$（仅 sqft\_living 一个代表）仍 0.5033——组信号被完整保留。
  \item \textbf{⑤ 原因归纳}：(a) ridge 解没有稀疏性，$|w_j|$ 小只代表被收缩多，不代表不重要；(b) 共线时 $|w_j|$ 不是可识别的重要性度量——权重可在组内任意重分配而拟合不变，ridge 最小范数解把权重“平摊”；(c) 阈值 $\tau$ 是人为的第二个超参数，无目标函数可优化；(d) $\ell_1$ 的零来自优化本身（KKT/软阈值），零集沿 $\lambda$ 单调嵌套、由单一超参数控制。
\end{itemize}

\subsection*{3. 与 sklearn 实现有拟合效果差异吗}

\textbf{题面：}你的模型相比于 sklearn 的实现有拟合效果上的差异吗？（简要说明即可）
（提示：可以在做完后两项实验后回答该题。）

\skeleton{结论要点，待扩写}
\begin{itemize}
  \item \textbf{换算对齐}（否则比较的是两个不同目标函数）：Ridge $\alpha=N\lambda_2$；Lasso $\alpha=\lambda_1/2$；ElasticNet $\alpha\rho=\lambda_1/2$ 且 $\alpha(1-\rho)=\lambda_2$；逻辑回归 $C=1/(2N\lambda_2)$（truth $N=5088$、$\lambda_2=10^{-3}$ $\Rightarrow$ $C\approx0.098$）。
  \item \textbf{结论：没有本质差异}。同一目标函数 + 充分收敛时两者同解（A2/A4 $\cos=1.00000$、relL2 $=0.002$；B2b $\cos$ 0.997）。观察到的差异全部可归为非模型因素：优化器机制、收敛预算（$\approx$ 隐式早停正则）、正则口径。
  \item \textbf{① 优化器机制}：固定步长全批量 GD 受稳定界约束——B3 raw L11 无正则 lr$=10^{-3}$（界 $\approx5.4\times10^{-4}$）第 8 轮 loss 爆炸自动停；sklearn 用精确求解器无此问题。
  \item \textbf{② 收敛预算 $\approx$ 隐式早停正则}：有限轮 GD 停在更小范数点、valid 反而更好（A1 306.55 $<$ 311.56；B1 223.58 $<$ 395.02；T2 ours 0.8867 $>$ 0.8600）；延长训练向 sklearn 靠拢（cos 0.897$\to$0.997）但 valid 可能回落（B2b 162.4 vs B2 150.4）。
  \item \textbf{③ 正则口径}：sklearn 默认 $C=1$（更强正则）valid 0.8500；不换算直接比会把“超参不同”误读成“实现差异”。
  \item 一句话：差异是\textbf{优化差异}（步长/求解器/预算/早停），不是模型或实现差异。
\end{itemize}

\subsection*{4. world：不同层中间表征的预测效果对比与选层}

\skeleton{结论要点，待扩写}

\subsection*{5. world：正则化与学习率的选择}

\textbf{题面：}你在最终模型提交中是怎么选择正则化的？请说明理由；

\skeleton{结论要点，待扩写}
\begin{itemize}
  \item \textbf{问题背景}：world 为 $N=500 \ll D=2560$ 的欠定问题，必须正则化；且原始特征尺度不齐，固定学习率的稳定界随层深暴跌（$1800\times$，详见 §附录~\ref{app:math}）——不先解决数值问题，扫正则没有意义。
  \item \textbf{① 特征标准化（z-score，统计量只取 train）}：把各界稳定界拉平到 $3.1$–$4.8\times10^{-3}$（仅 1.5 倍差距），同一 lr 对所有层公平；$\lambda_2$ 的真实作用在标准化后才显形。
  \item \textbf{② $\lambda_2$ 呈 U 形}：$\lambda_2=0.1$ 时训练残差 $\approx3$ 但 valid MSE 209（严重过拟合）；$\lambda_2=1.0$ 最优（167.06）；$3.0$ 回升（184.57）。标准化版扫描固定 lr$=3\times10^{-3}$。
  \item \textbf{③ $\lambda_1$}：truth 的扫描显示 $\lambda_1$ 对大表征有害（稠密表征，见 Q9）；world 提交沿用 $\lambda_1=0.001$（小量、与扫描一致，未观察到收益）。
  \item \textbf{④ 学习率在稳定界内选取}：raw L11 界 $5.4\times10^{-4}$ $\Rightarrow$ lr$=5\times10^{-4}$（贴线，MSE 150.43）；z-score 版 L11 界 $3.6\times10^{-3}$ $\Rightarrow$ lr$=3\times10^{-3}$（0.83 倍余量，167.06）。训练脚本另有发散兜底（lr$\times$0.5 重试 $\le$4 次）。
  \item \textbf{最终选择}：raw L11，lr$=5\times10^{-4}$，ep2000，$\lambda_2=0.1$（MSE \textbf{150.43}）；备选 z-score L11，lr$=3\times10^{-3}$，$\lambda_2=1.0$（167.06）。两者差 17 不显著（SE 13–19）$\Rightarrow$ 按简单性（权重直接可用、无须再标准化）选 raw。
  \item 论据链：稳定界公式与对拍表见 §附录~\ref{app:math}；扫描全表见 §附录~\ref{app:exp}。
\end{itemize}

\section{背景知识：线性探测、Qwen3-4B 与两个任务}\label{app:background}

\skeleton{背景素材，成文时自由组织（附录不直接记分，建议 0.5–1 页）}
\begin{itemize}
  \item \textbf{线性探测（linear probing）}：冻结 LLM，在某一中间层的表征上训练简单线性模型（回归/分类），以判断目标信息在该层是否\textbf{线性可分地存在}（Alain \& Bengio, 2018 [1]）。本实验考察 Qwen3-4B-Base 的\textbf{空间坐标}（论文 [3]）与\textbf{句子真假}（论文 [4]）两类表征。
  \item \textbf{特征口径}：$0$–$35$ 共 36 个解码器块的输出（final RMSNorm 之前），$D=2560$；world 取“国家名最后一个 token”，truth 取“句子最后一个 token”；训练时 \texttt{float16}$\to$\texttt{float64}。
  \item \textbf{两任务规模}：world train 500 / valid 130（回归，目标 lat+lon）；truth train 5088 / valid 300（二分类，标签对称）。world 为热身（$N\ll D$）；truth 为效果主考察。
  \item \textbf{提交物}：world \texttt{weights} $(2,2560)$ + \texttt{bias} $(2,)$；truth \texttt{weights} $(2560,)$ + \texttt{bias} 标量；均 \texttt{float64}，另有输入层号（整数）。
  \item \textbf{本实验两个任务的数据集不公布构造方式}（world），truth 的来源经我们反推与对拍做了解释（见 Q8 / §\ref{app:exp}）。
\end{itemize}

\section{有意思的实验：超参数扫描、稳定界与工程实践}\label{app:exp}

\skeleton{附加内容（报告 §2.4）素材，成文时压缩为 1–2 页}
\begin{itemize}
  \item \textbf{超参数扫描（job 88653，9 组 35 run）}：两任务在 L11 上分别扫 lr / epochs / $\lambda_1$ / $\lambda_2$，L11/23/35 扫 layer。要点：truth lr$=0.005$（68.7\%）、ep$\ge$2000；world lr$=5\times10^{-4}$（150.94）、ep2000、$\lambda_2=0.1$（150.43）；truth layer 23（84.3\%）；world layer 23/35 直接发散（inf）——引出数值修复。
  \item \textbf{world 数值修复 + 重扫（job 89085，16 run）}：根因 = 学习率越过\textbf{按层稳定界}（§\ref{app:math}）；z-score 后 lr$=3\times10^{-3}$ 三层均安全、$\lambda_2$ 呈 U 形（1.0 最优 167.06）；lr$=5\times10^{-3}$ 被正确判为发散。三条独立路径交叉验证“L11 是 world 最优层、深层收敛后确实更差”。
  \item \textbf{稳定界（数值问题的数学根因）}：lr $< 2/\lambda_{\max}(H) = N/\|X\|_2^2$，只依赖特征矩阵；13 层 $\times$ 两任务 $\times$ raw/z-score 全表见 §\ref{app:math}。raw 界随深度暴跌 1800$\times$、z-score 后拉平到 1.5$\times$。

\end{itemize}

\section{有趣的表征：跨任务对照与现象观察}\label{app:repr}

\skeleton{表征研究素材，成文时压缩为 1–2 页（图可复用正文）}

  \item \textbf{两任务最优层带不同}：world 在\textbf{浅层} L2–L11、truth 在\textbf{中层} L17–L23，且都在 L32–L35 变差——位置/坐标信息与真假语义的“可线性解码深度”不同（对照论文 [3] 约 60\% 深度、论文 [4] 中层，我们 world 的浅层结果与之不同，如实报告）。

\section{数学原理：稳定界、闭式解与 KKT}\label{app:math}

\skeleton{数学素材，成文时压缩为 1.5–2 页}
\begin{itemize}
  \item \textbf{全批量 GD 稳定界（world）}：$L=\|Xw+b\mathbf{1}-y\|^2/N$ 的 Hessian $H=2X^{\top}X/N$；误差传播 $e_{t+1}=(I-\mathrm{lr}\cdot H)e_t$ 收敛 $\Leftrightarrow$ $\mathrm{lr}<\dfrac{2}{\lambda_{\max}(H)}=\dfrac{N}{\|X\|_2^2}$——只依赖特征矩阵、与 $y$ 无关，每层一个值。越界后误差沿最大特征方向每轮 $\times|1-\mathrm{lr}\,\lambda_{\max}|>1$ 指数放大。
  \item \textbf{logistic 的松弛}：$H_{\log}\preceq X^{\top}X/(4N)$，最坏情形充分界 $\approx 8N/\|X\|_2^2$；且梯度有界（$p-y\in[-1,1]$），越界表现为震荡/饱和而非爆炸——这是 truth 可以不标准化、lr$=0.005$ 的原因。
  \item \textbf{13 层稳定界全表}（$N/\|X\|_2^2$，越小越危险）与实测对拍（节选：raw L11 界 $5.4\times10^{-4}$，lr$=5\times10^{-4}$ 稳定、$10^{-3}$ 溢出；std L35 界 $4.8\times10^{-3}$，lr$=4\times10^{-3}$ 稳定、$8\times10^{-3}$ 第 9 轮爆炸）。
\end{itemize}

\skeleton{数学要点续}
\begin{itemize}
  \item \textbf{Ridge 的 SVD 闭式解}（Q1/Q2 实现）：$X=U\Sigma V^{\top}$，$\hat w= V\,\mathrm{diag}\!\big(\sigma_i/(\sigma_i^2+\lambda)\big)\,U^{\top}y$；$\lambda=0$ 退化为最小范数最小二乘（伪逆解）。用于系数路径的精确计算（与 sklearn 对拍 $10^{-9}$）。
  \item \textbf{Lasso 的 KKT / 软阈值}（Q1/Q2 实现）：$\partial L/\partial w_j=\frac{2}{N}[X^{\top}(Xw-y)]_j+\lambda_1\, \mathrm{sgn}(w_j)+2\lambda_2 w_j=0$；坐标下降 + warm start；精确零来自优化几何，零集沿 $\lambda$ 嵌套（与 Q2 的阈值化 ridge 对照）。
  \item \textbf{逻辑回归梯度}（\texttt{model.py}）：$\nabla_w L=\frac{1}{N}X^{\top}(\hat y-y)+\lambda_1\,\mathrm{sgn}(w)+2\lambda_2 w$；数值稳定：$\log(1+e^{-z})=\mathrm{logaddexp}(0,-z)$。
  \item \textbf{sklearn 换算表}：Ridge $\alpha=N\lambda_2$；Lasso $\alpha=\lambda_1/2$；ElasticNet $\alpha\rho=\lambda_1/2$、$\alpha(1-\rho)=\lambda_2$；Logistic $C=1/(2N\lambda_2)$。（量纲陷阱：sklearn 的 $\alpha$ 是“平方误差总和”口径。）
  \item \textbf{基线口径与 $R^2$}：train-mean 基线的元素平均口径 MSE $=3311.27$（与模型同口径）；坐标求和口径 $=6622.54$。混用会把 $R^2$ 抬高约 2.3pp；统一后 world 最佳 $R^2=0.9546$（RMSE $\approx$ 12.3$^\circ$）。
\end{itemize}
