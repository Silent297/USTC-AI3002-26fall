# Q9 truth L11 超参数扫描图（88653）

## 这是什么

`experiments/plot_q9_sweep.py` 读取 `results/slurm_grid/20261009_115559_88653/results.json`，画 truth 在 L11 上的 4 个单变量面板（原始特征、logistic、其余超参固定为 lr=5e-3、500 轮、λ1=λ2=1e-3）：

- lr、epochs：红圈为该面板扫描最优；
- λ1、λ2：不标扫描最优，绿菱形标提交实际采用的 λ1=λ2=1e-3（避免把 λ1=0 误读成推荐值）；
- layer 面板不画（13 层曲线与选层理由在 Q9 正文图/表）。
- 图：`results/q9_grid/plots/truth_sweep.{png,pdf}`。

## 精确读数

| 面板 | 取值 → valid accuracy |
|---|---|
| lr（fixed: epochs=500, λ1=λ2=1e-3） | 5e-4→0.6367; 1e-3→0.6500; 2e-3→0.6767; 5e-3→0.6867; 1e-2→0.6300 |
| epochs（fixed: lr=5e-3, λ1=λ2=1e-3） | 200→0.6767; 500→0.6867; 1000→0.7033; 2000→0.7300 |
| λ1（fixed: lr=5e-3, epochs=500, λ2=1e-3） | 0→0.7000; 1e-3→0.6867; 1e-2→0.6700; 0.1→0.5000 |
| λ2（fixed: lr=5e-3, epochs=500, λ1=1e-3） | 0/1e-3/1e-2/0.1 全部→0.6867 |

## 结论

1. lr 倒 U：5e-3 峰值 68.7%，1e-2 回落到 63.0%，5e-4 欠拟合 63.7% ⇒ 最终取 lr=5e-3。
2. epochs 在扫描范围内单调升；扫描只到 2000 轮（73.0%），最终 13 层训练统一加长到 5000 轮（L11 实测 74.0%）。
3. λ1 有害：1e-3→1e-2→0.1 单调下滑，0.1 掉到随机 50.0%；λ1=0 的 70.0% 略高于 1e-3，但无正则的 MLE 在近似可分数据上不稳定（Q3 T1 的 sklearn 对数损失 27.77），故保留 1e-3 弱正则。
4. λ2 四个取值完全重合（68.7%）⇒ 不敏感，取 1e-3 与 λ1 对齐即可。

## 报告用法

- Q9（3）：λ1 有害、λ2 不敏感、弱正则 + 有限轮预算的依据。
- Q9（4）：lr=5e-3 来自本扫描；epochs 扫描终点 2000 与最终 5000 轮的差异由图注说明。
- 红圈只表示该格扫描最优；λ1/λ2 的绿菱形表示提交配置，两者不混用。
