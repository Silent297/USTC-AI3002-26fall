# raw L2 粗筛逐图说明

数据：`results/l2_sweep/raw_coarse/results.json`（13 次训练；raw 特征，layer=2，epochs=2000，λ1=1e-3）
图：`plots/l2_raw_coarse.{png,pdf}`（左：lr × λ2 热图；右：valid MSE 随 lr 的折线，三条线对应三个 λ2）
复现命令：

```bash
python experiments/run_grid.py --config experiments/hparam_grid_l2_raw.json \
  --out results/l2_sweep/raw_coarse/results.json \
  --artifacts-dir results/l2_sweep/raw_coarse/weights
python experiments/plot_l2_coarse.py
```

## 图是什么

- 左图 4×3 热图：每格是该 (lr, λ2) 组合的 valid MSE，颜色越黄越低；红框标出全场最优（lr=4e-3、λ2=1e-2、MSE 167.36）。
- 右图把同一组数据按 lr 展开，三条线分别对应 λ2=1e-3 / 1e-2 / 0.1；lr=5e-3 的 run 发散（finite=False，MSE≈3.74e9），未画入曲线，只以文字标注。
- 所有 run 都固定 epochs=2000、λ1=1e-3；raw 特征不做标准化。

- 旧探针（lr=5e-4、λ2=0.1）复算 **198.7822**，与 `results/_probe_raw_l2` 的 198.782247 逐位一致，说明本管线没有接错。
- 最优：**lr=4e-3、λ2=1e-2、valid MSE=167.3580**（27.2 s）。
- 发散点：lr=5e-3、λ2=1e-3，lat/lon 分别在第 262/294 轮爆炸（loss 1.0e9/6.1e9），`finite=False`，MSE 3.736e9。

## 结论

1. **旧 raw L2 的 198.78 是欠拟合，不是 L2 的真实上限。** 把 lr 从 L11 的 5e-4 提到 L2 自己的 4e-3，MSE 降了 **31.42**（198.78→167.36）。这印证了稳定界分析：raw L2 界 4.95e-3，5e-4 只用到 0.10× 界。
2. **MSE 点估计不占优，但统计上与 L11 打平。** 167.36 比 std L2 的 157.57 高 **9.79**，比 raw L11 的 150.43 高 **16.93**；同点配对 bootstrap（10k）95% CI 分别为 **[-2.34, +23.09]** 与 **[-14.66, +53.13]**，都跨 0。因此不能说 raw L2“显著更差”，只能说 MSE 点估计排第三。
3. **典型误差反而略好，但也不显著。** raw L2 的中位距离 **855.3 km**，低于 raw L11 的 953.8 km 与 std L2 的 973.8 km；平均距离 1122.7 vs 1141.7 / 1125.2 km；R² 0.9494 vs 0.9545 / 0.9524。配对“距离差的 median”为 **−5.7 km**（95% CI [-89.1, +131.2]），跨 0。MSE 吃亏主要来自尾部离群点：中位平方误差 36.5（L11 45.3、std L2 43.6），但少数大误差把均值拉高。⇒ 若报告用中位距离作辅助指标，raw L2 有竞争力；按课程主指标 MSE，它仍排第三。
4. **λ2 的最优点在 1e-2 附近**：三个 lr 下 1e-2 都是最低或接近最低；0.1 一致更差。lr 在 4e-3 仍未完全饱和，但已贴近 4.95e-3 的稳定界，继续加大会像 5e-3 一样发散。
5. **策略含义**：若确定以 L2 为提交层，按 MSE 应先调 **z-score 分支**（现有 157.57，lr=2e-3 仅 0.49× 界，还有上移空间）；raw L2 的 167.36 只能作为“原配置确实欠拟合 + 典型误差不差”的对照证据，不足以单独支撑换层。

## 报告用法（若写入）

- 可放在 Q4 的“选层”或 Q5 的“正则/学习率”讨论里，作为一段公平性修正：**原 raw L2 探针套用了 L11 的 lr，低估了 L2；按 L2 自己稳定界重调后 raw L2=167.36，MSE 点估计仍低于 std L2 与 raw L11，但差异不显著，中位误差反而略低**。
- 不要把这个结果写成“L2 最优”，也不要写成“L2 显著更差”；准确口径是“MSE 点估计第三、统计上与 L11 打平；中位误差略好但不显著”。
- 读数时注意：13 个配置在 130 条 valid 上选最优，存在选择偏差；上面的配对 CI 是选参后的条件比较，偏乐观，只能作参考，不能替代独立测试集。

## 复现性/口径

- 全批量 GD、NumPy 确定性代码；lat/lon 分别拟合，MSE 为元素平均（与报告 Q4–Q6 一致）。
- 权重已折回原始特征空间，保存在 `weights/<run>/weights.npz`；最优 run 的权重可直接用于后续 Q6/Q7（若切 L2）。
- 训练时间：26–34 s/次（本轮包含首次加载特征的开销；旧记录 0.3–14 s 是热缓存/不同进程条件下的数）。
