# Q4 world 分层图（std-only 重绘）

## 这是什么

`experiments/plot_layers.py` 读取 `results/slurm_layers/world/results.json`，只用 13 个 `kind=layer`（z-score 统一配置：lr=2e-3、2000 轮、λ1=1e-3、λ2=1.0）的权重，在 valid 130 条上重算 MSE。

- 上：各层 valid MSE，误差棒 = 均值 ±1 SE；红圈 = std 中最低层。
- 下：与参考层 L2 的配对差（同 130 条 valid），误差棒 = 95% CI。
- 本轮按用户要求用 `--no-extra` 重绘，图/表不再包含 raw L11 extra（150.43）。该 run 仍保留在 `results.json` 与第 5 题中，只是不属于“固定配置的层间对照”。

## 结论

1. 固定配置下 L2 最低（157.57），L5/L8/L11 与其差 1.6–9.5，95% CI 均跨 0，浅层平台内部不可区分。
2. 中层 L14–L26 明显变差：L17/L20/L23 的配对差 CI 不含 0（显著），L14/L26 为边缘；谷底约 241。
3. 深层回升到 L32=180.31，但与 L2 差 +22.7±54.1，仍不显著。

## 关于“交换 L2/L11 数值”

没有交换，也不能交换：`results.json` 与保存的权重都给出 L2=157.5709、L11=167.0413（本次又各自独立复算了一遍）。层标签也有旁证：特征范数随深度单调上升（train 均值 L2=19.35、L5=36.09、L11=51.29），且 L11 与 L8/L14 的相似度（0.696/0.785）远高于与 L2（0.456）。把两个数值对调会与权重、附录扫描表和第 5 题冲突，属于改数据，故只做了“去掉 extra、保留真实 std 值”的重绘。
