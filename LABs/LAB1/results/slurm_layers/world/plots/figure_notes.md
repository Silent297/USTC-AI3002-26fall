# Q4 world 分层图（std 13 层 + raw L11 extra）

## 这是什么

`experiments/plot_layers.py` 读取 `results/slurm_layers/world/results.json`，在 valid 130 条上从保存的权重复算 MSE：

- 上：13 个 z-score 统一配置层（lr=2e-3、2000 轮、λ1=1e-3、λ2=1.0）的 valid MSE，误差棒 = 均值 ±1 SE；红圈 = std 中最低层 L2（157.57）；红星 = raw L11 extra（150.43，另一套超参）。
- 下：各层与参考层 L2 的配对差（同 130 条 valid），误差棒 = 95% CI。

图中同时保留 std 曲线与 raw extra，是为了让第 4 题（4）的“raw L11 略优于 L2”这一判断在图上可见；raw extra 不属于固定配置的层间对照，只作参考点。

## 结论

1. 固定配置下 L2 最低（157.57），L5/L8/L11 与其差 1.6–9.5，95% CI 均跨 0，浅层平台内部不可区分。
2. 中层 L14–L26 明显变差：L17/L20/L23 的配对差 CI 不含 0（显著），L14/L26 为边缘；谷底约 241。
3. 深层回升到 L32=180.31，但与 L2 差 +22.7±54.1，仍不显著。
4. raw L11 extra（raw 特征、lr=5e-4、λ2=0.1）为 150.43，比 std L2 低 7.1，但这是超参差异，不是层间差异；两者不显著（正文 Q5 有 t 检验）。

## 关于“交换 L2/L11 数值”

没有交换，也不能交换：`results.json` 与保存的权重都给出 L2=157.5709、L11=167.0413（本次又各自独立复算）。层标签有旁证：特征范数随深度单调上升（train 均值 L2=19.35、L5=36.09、L11=51.29），且 L11 与 L8/L14 的相似度（0.696/0.785）远高于与 L2（0.456）。对调数值会与权重、附录扫描表和第 5 题冲突，属于改数据。
